Physical Windows reboot is deferred to the next version at the user's direction.

**Status meanings:** PROVEN means a source path plus a relevant test or recorded probe supports the stated behavior; it does not imply full release acceptance. INCOMPLETE means a material requested capability or evidence is missing. UNAVAILABLE_BY_PROTOCOL means the current Codex telemetry surface does not provide the requested exact measurement. NEEDS_LIVE_VALIDATION means implementation exists but requires installed Windows runtime/interaction evidence. DEFERRED_BY_USER marks work explicitly moved to the next version.
