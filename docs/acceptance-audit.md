**Status meanings:** PROVEN means a source path plus a relevant test or recorded probe supports the stated behavior; it does not imply full release acceptance. NEEDS_LIVE_VALIDATION means implementation exists but requires installed Windows runtime/interaction evidence. DEFERRED_BY_USER marks work explicitly moved to the next version.
