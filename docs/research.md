### License and attribution rule

The license evidence above is the actual license text committed at the pinned revision. MIT and Apache-2.0 permit reuse subject to their terms, but the current plan is architecture and protocol reference only, so no third-party source attribution is needed for copied code. If code is later adopted, add its copyright/license notice to `THIRD_PARTY_NOTICES.md` and preserve required notices. `manuelsh/codex-monitor` remains reference-only because its claimed MIT status has no committed license text at the inspected revision.

## Codex data source findings

The pinned `openai/codex` source is the preferred contract for local Codex reads:

- `account/rateLimits/read` and `account/rateLimits/updated` carry structured `primary` / `secondary` windows, percentages, duration and reset information; missing or stale values must stay unavailable rather than be inferred. See the pinned [account protocol](https://github.com/openai/codex/blob/e95abcdf4939f37f11f00f984efdbbf8b088346/codex-rs/app-server-protocol/src/protocol/v2/account.rs).
- The protocol has explicit Thread Goal states and get/set/clear methods. See the pinned [thread protocol](https://github.com/openai/codex/blob/e95abcdf4939f37f11f00f984efdbbf8b088346/codex-rs/app-server-protocol/src/protocol/v2/thread.rs).
- Model metadata is catalog-driven: model IDs, display names, reasoning support, service tiers, speed tiers and context-related metadata are not a fixed application enum. Preserve observed model IDs and mark unsupported/unknown price mappings as unavailable.
- Session JSONL and app-server usage are useful local telemetry. They are not subscription billing records and do not reveal a reliable token-to-quota conversion. Never derive subscription quota impact from token totals.
- Third-party quota clients that call ChatGPT usage routes may be useful for comparison but rely on an undocumented/unversioned service contract. Keep any such fallback isolated, explicitly labeled, and disabled for recovery decisions unless independently validated.
