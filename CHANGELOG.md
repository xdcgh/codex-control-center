# Changelog

## 0.1.0 preview - 2026-10-11

- Preserve and import the verified Node watchdog with 25 baseline tests.
- Document phased Windows Control Center development and Tauri/Node architecture.
- Preserve private runtime and rollback separately from publishable source.
- Add Core v2 live quota polling, durable recovery scheduling, compatibility probes and authenticated native broker.
- Add the Windows dashboard, Thread/Goal controls, quota charts, token/pricing/performance views, tray and widget.
- Separate nonadditive counter inventory from token consumption; expose source quality and unavailable measurements.
- Bundle dependency licenses and verify the actual installed NSIS payload against portable resources.
- Record real recovery episodes separately from simulated triggers and incomplete Goal outcomes.
- Add Simplified Chinese and English throughout the interface, automatic Windows language selection and manual overrides.
- Credit xudc2 and Codex in the localized About panel and README.
- Show diagnostics sources and coverage, on-demand official account activity, current Goal counters and future-event repository groups.
- Observe bounded tool requests and explicit execution events with source freshness, privacy and coverage checks; inactivity hints never initiate recovery.

This unsigned preview has 199 passing Windows Node tests, successful Core/package CI and verified installed/portable payloads. Natural-cycle completion and visible toast presentation remain unverified; the project owner accepted those evidence limits for this version. Physical Windows reboot work is deferred to the next version.
